# 心理咨询历史会话与重命名设计

## 目标

让心理咨询页的历史会话能够正确展示、切换和识别，并提供类似 ChatGPT 的轻量重命名体验。改动只覆盖历史会话列表、会话加载和重命名，不扩展为复杂的会话管理后台。

## 已确认交互

- 侧边栏按最近更新时间倒序展示会话，标题优先使用用户保存的名称；没有保存名称时，取该会话第一条用户消息并截断为可读标题。
- 当前会话使用浅色背景和左侧强调线标识；点击会话加载对应消息。
- 每条会话右侧提供省略号菜单，菜单内包含“重命名”。
- 点击“重命名”后在原位置显示输入框并选中现有标题；按 `Enter` 或点击确认按钮保存，按 `Esc` 或点击空白处取消。
- 标题去除首尾空格后必须为 1～30 个字符，允许不同会话使用相同标题。
- 手动重命名后永久保留，后续发送消息不会覆盖保存的标题。保存失败时恢复原名称并显示明确提示。
- 空列表显示“暂无历史会话”；加载失败显示错误提示和“重新加载”入口，不能再静默伪装为空列表。

## 技术方案

采用独立的 `counseling_session_metadata` 会话元数据表，以 `(user_id, session_id)` 唯一约束保存可选标题。现有 `counseling_sessions` 继续只负责消息记录，避免在每一条消息上重复存储标题，也不对现有历史消息做破坏性迁移。

Node/Express 增加重命名接口 `PATCH /api/counseling/sessions/:id`，请求体为 `{ title: string }`。服务端校验标题长度，并通过 `user_id + session_id` 验证会话属于当前登录用户；不存在或不属于当前用户时统一返回未找到，避免泄露其他用户的会话信息。会话列表查询关联元数据表，并在没有自定义标题时读取第一条用户消息作为默认标题。

前端 API 层补充 `renameSession`。页面直接使用统一请求层已经解包后的返回值，修复当前多取一层 `data.data` 导致列表和消息始终为空的问题。重命名成功后更新本地列表；失败时保留旧标题并提示用户。

## 数据流

1. 打开侧边栏时，Vue 调用会话列表接口，Node 从消息表聚合时间和数量，并关联元数据标题后返回。
2. 点击会话时，Vue 请求该用户对应的会话消息，成功后替换聊天区内容；失败时保留当前内容并提示。
3. 用户确认重命名时，Vue 调用 PATCH 接口；Node 完成校验与归属检查后写入元数据表，再返回最终标题。
4. 新会话首次产生消息后自动出现在列表中，默认标题取第一条用户消息；若已手动重命名则始终以保存标题为准。

## 测试与验收

- 服务层测试覆盖默认标题、手动标题优先、仅允许重命名自己的会话、空标题和超长标题拒绝。
- 控制器/接口测试覆盖成功、参数错误、会话不存在，以及统一响应结构。
- 前端测试覆盖请求结果直接解包、历史会话切换、重命名保存与失败回滚。
- 类型检查和构建通过；浏览器验收至少包含历史列表可见、切换后消息正确、刷新后名称仍保留、移动端侧边栏可操作。

## 非目标

本次不加入批量管理、置顶、归档、跨用户共享、AI 自动总结标题或无限滚动。删除功能不属于本次两个已确认目标，避免扩大范围。
