## 1. 已完成内容

1. 应用边界：新增 `createApp()`，导入应用时不连接数据库、不监听端口；生产入口统一为 `src/server.ts` / `dist/server.js`，由其负责数据库连接和端口监听。
2. API 契约：成功响应固定为 `{ code: 0, message, data }`；400、404、500 使用非零业务码和标准 HTTP 状态；生产环境 5xx 不返回原始错误或堆栈。健康检查已纳入统一契约。
3. 后端功能停用：`FEATURE_NON_CORE_MODULES_ENABLED=false` 为安全默认值。活动、社区帖子、课程、音乐、放松、成就路由关闭时不再顶层导入，对应请求返回 HTTP 503、业务码 1403 和“功能未启用”，测试断言请求期间数据库查询为 0 次。
4. 前端功能停用：`VITE_FEATURE_NON_CORE_MODULES_ENABLED=false` 为安全默认值。默认隐藏放松、成就通知和后台非核心管理入口；活动、社区、资源、课程、音乐、放松、成就路由被过滤，直接 URL 进入 404。`/improve` 保留核心测评入口并默认跳转 `/improve/survey`。

## 3. SQLite 阻断结论与边界

自动化测试把六个非核心路由模块设置为“一旦导入立即失败”，关闭模式下测试仍通过，证明这些旧路由及其模型初始化链没有被加载；逐个请求关闭接口时，数据库查询 mock 调用次数保持为 0。测试日志仍出现 Node.js 的 SQLite 实验特性警告，这是核心用户、情绪、测评等尚未迁移路径加载旧数据库配置所致，不代表关闭接口访问了 SQLite。核心路径的 MySQL 切换属于后续阶段 D/E，本阶段没有提前改写或删除旧 SQLite 数据。
