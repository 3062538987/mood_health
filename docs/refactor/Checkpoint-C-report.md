## 1. 已完成内容

1. 前端请求边界：`request.ts` 统一校验 `{ code, message, data }`，成功业务码固定为 `0`，只解包一次并向页面返回业务数据；HTTP、业务、网络和请求配置错误统一为 `ApiRequestError`。旧响应兼容被限制在显式兼容闸门内，便于后续清退。
2. 认证契约：登录统一返回 `{ token, user }`，当前用户接口统一返回 `{ user }`；后端不返回密码字段，前端 Store 与路由恢复流程直接消费业务 DTO。
3. 情绪契约：情绪新增、列表、详情、更新和删除统一使用完整响应信封；分页参数和前端 DTO 明确化，控制器契约测试不接触旧 SQLite 数据。
4. 心理测评契约：问卷列表、详情、问题、提交和历史统一响应；保留原有 SDS/SAS 计分与阈值，不新增心理指标，并把结果表述统一为“筛查类型、风险分层、风险提示”，明确“不替代专业评估或医学诊断”。
5. 管理与审计契约：统一管理端响应和鉴权错误；管理端情绪列表不再查询、解密、返回或导出 `note`、`trigger`；审计接口改为字段白名单，不返回 `content` 和 `ip_address`；学生访问管理接口返回 HTTP 403、非零业务码。
