# V1.1 实施计划

## 1. 状态

- 分支：`codex/p0-phase-a`
- 上游：V1.1 AI 增强 PRD 已批准
- 架构：MySQL 8.4 + Repository 模式 + DeepSeek API

## 2. 任务清单

### V1.1-T1：prompt_templates 表 Migration

**目标**：创建 Prompt 模板存储表。

**内容**：
- 创建 `0180_create_prompt_templates.up.sql` 和 `down.sql`
- 包含 UNIQUE 约束、分类索引、启用状态索引

**验收**：
- `npm run db:migrate` 退出 0
- `up → down → up` 完整测试通过

### V1.1-T2：PromptRepository + PromptService + PromptController

**目标**：实现 Prompt 模板的完整 CRUD。

**内容**：
- `PromptRepository`：findAll、findById、findByCategory、findActiveByCategory、create、update、remove
- `PromptService`：listTemplates、getTemplate、createTemplate、updateTemplate、deleteTemplate、getActiveByCategory
- `PromptController`：listPrompts、getPrompt、createPrompt、updatePrompt、deletePrompt（含审计日志）
- `promptRoutes.ts`：5 个路由，全部需 `prompt.manage` 权限

**验收**：
- 新增 `promptRepository.test.ts` 全部通过
- 新增 `promptService.test.ts` 全部通过
- 新增 `promptController.test.ts` 全部通过

### V1.1-T3：AI 客户端实现

**目标**：封装 DeepSeek Chat Completion API，提供统一调用入口。

**内容**：
- `utils/ai/aiClient.ts`：`AIClient` 类 + `callChatCompletion()` 函数
- `utils/ai/aiCallService.ts`：`callWithTemplate()` + `callDirect()` + `isAiAvailable()`
- `config/aiConfig.ts`：AI 配置管理（环境变量驱动）
- 支持：鉴权、重试（指数退避 3 次）、错误分类（401/429/其他）

**验收**：
- 新增 `aiClient.test.ts` 全部通过
- AI_ENABLED=false 时正确抛出错误
- API Key 无效时返回 401 错误

### V1.1-T4：AI 量表解读

**目标**：学生提交量表后可获取 AI 解读。

**内容**：
- `services/aiAssessmentService.ts`：`generateInterpretation()` — 根据 scaleType 选择模板，调用 callWithTemplate
- `controllers/aiInterpretationController.ts`：`interpretAssessmentHandler` + `validateInterpretation`
- `routes/aiInterpretationRoutes.ts`：`POST /api/ai/interpret`
- 前端 `src/api/ai.ts`：`getInterpretation()` API 调用
- 前端 `QuestionnaireResult.vue`：AI 解读按钮 + Markdown 渲染 + 免责声明

**验收**：
- 新增 `aiAssessmentService.test.ts` 全部通过
- 前端可点击"AI 智能解读"并显示结果
- 模板不存在时返回 404
- AI 未启用时返回 503

### V1.1-T5：AI 情绪报告

**目标**：基于情绪记录生成 AI 周报/月报。

**内容**：
- `services/aiMoodReportService.ts`：`generateWeeklyReport()` + `generateMonthlyReport()`
- `controllers/aiInterpretationController.ts`：`generateMoodReportHandler` + `validateMoodReport`
- `routes/aiInterpretationRoutes.ts`：`POST /api/ai/report`
- 前端 `src/api/ai.ts`：`getMoodReport()` API 调用

**验收**：
- 新增 `aiMoodReportService.test.ts` 全部通过
- 周报和月报使用不同模板
- `type` 参数校验（weekly/monthly）

### V1.1-T6：AI 路由与限流

**目标**：AI 转发路由 + 频率限制。

**内容**：
- `routes/aiRoutes.ts`：通用 AI 代理路由（转发到 Python AI 服务）
- 限流：`express-rate-limit` 15分钟/30次
- 树洞场景：本地温柔文案降级（不依赖外部 AI）
- `AI_ENABLED` 总开关：关闭时返回提示

**验收**：
- 限流超限返回 429
- AI_ENABLED=false 返回优雅提示
- 树洞场景不调用外部 API

### V1.1-T7：权限扩充

**目标**：新增 `prompt.manage` 权限。

**内容**：
- 更新 `coreSeed.ts` 中 `ROLE_PERMISSION_CODES`，为 super_admin 分配 `prompt.manage`
- 更新 `reference` seed 的角色权限映射

**验收**：
- `npm run seed` 退出 0
- 权限验证测试通过
