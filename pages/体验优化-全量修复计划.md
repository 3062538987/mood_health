## Step 1: 修复木鱼敲击 - 动画与反馈

**文件**: `src/components/relax/MoodWoodenFish.vue`

**问题**:
1. 点击木鱼只有 `scale(0.95)` 缩放，用户看不到明显反馈
2. 音效文件 `/audio/effects/woodenFish.mp3` 不存在
3. 缺少敲击的弹跳/震动动画

**修复方案**:
1. 添加木鱼敲击的弹跳动画（上下弹跳 + 轻微旋转）
2. 添加敲击波纹扩散效果
3. 木鱼敲击后短暂变亮（发光效果）
4. 用 CSS animation 替代 setTimeout 控制动画
5. 音效播放失败时静默降级，不影响交互

**具体改动**:
```scss
// 替换 .wooden-fish 的 tapping 样式
.wooden-fish {
  position: relative;
  cursor: pointer;
  transition: transform 0.15s cubic-bezier(0.34, 1.56, 0.64, 1);
  user-select: none;

  &.tapping {
    animation: fishKnock 0.4s ease-out;
  }

  // 波纹效果
  &::after {
    content: '';
    position: absolute;
    top: 50%; left: 50%;
    width: 0; height: 0;
    border-radius: 50%;
    background: rgba(255, 215, 0, 0.3);
    transform: translate(-50%, -50%);
    pointer-events: none;
  }

  &.tapping::after {
    animation: ripple 0.6s ease-out;
  }
}

@keyframes fishKnock {
  0% { transform: scale(1) rotate(0deg); }
  20% { transform: scale(0.85) rotate(-3deg); }
  40% { transform: scale(1.05) rotate(1deg); }
  60% { transform: scale(0.95) rotate(-1deg); }
  100% { transform: scale(1) rotate(0deg); }
}

@keyframes ripple {
  0% { width: 0; height: 0; opacity: 1; }
  100% { width: 200px; height: 200px; opacity: 0; }
}
```

## Step 6: 修复情绪记录标签挤压

**文件**: `src/views/mood/MoodRecord.vue`

**问题**:
1. `.mood-grid` 使用 `min-width: 760px` 强制横向滚动
2. 移动端标签被挤压，需要滑动才能看到全部
3. 标签间隙小，视觉拥挤

**修复方案**:
1. 响应式网格：桌面端 8 列，平板 4 列，手机 3 列
2. 移除 `min-width: 760px` 硬编码
3. 标签尺寸自适应，减小 padding 和 emoji 大小
4. 添加横向滚动条样式美化（::-webkit-scrollbar）
5. 每行标签添加分类标题的视觉锚点

**具体改动**:
```scss
.mood-grid {
  display: grid;
  grid-template-columns: repeat(8, minmax(80px, 1fr));
  gap: 0.5rem;
  // 移除 min-width: 760px;
  
  @media (max-width: 1024px) {
    grid-template-columns: repeat(4, minmax(72px, 1fr));
  }
  
  @media (max-width: 640px) {
    grid-template-columns: repeat(3, minmax(64px, 1fr));
  }
}

.mood-grid-scroll {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
  scrollbar-width: thin;
  
  &::-webkit-scrollbar { height: 4px; }
  &::-webkit-scrollbar-thumb { background: var(--border-color); border-radius: 4px; }
```
