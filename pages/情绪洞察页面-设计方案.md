# 情绪洞察页面 - 设计方案

## 一、你的想法很好，我帮你梳理一下

你要的本质是：**让用户不仅记录情绪，还能"看懂"自己的情绪**。目前只有记录功能，用户记录完就完了，看不到任何反馈——这就像一个日记本只能写不能翻。加一个洞察页，把数据变成图表+AI分析，整个体验就完整了。

---

## 二、页面定位

**名称**：情绪洞察（MoodInsight）

**位置**：放在情绪模块下，作为第三个 Tab（记录 → 档案 → **洞察**）

**一句话描述**：用图表和AI帮你读懂自己的情绪变化规律。

**目标用户**：学生用户（查看自己的情绪数据）

## 四、四个时间维度

| 维度 | 数据范围 | 图表粒度 | 适用场景 |
|------|----------|----------|----------|
| 日 | 今天 | 按小时 | 查看今天的情绪波动 |
| 周 | 最近7天 | 按天 | 了解本周情绪变化 |
| 月 | 最近30天 | 按天/按周 | 发现月度规律 |
| 年 | 最近12个月 | 按月 | 看到长期趋势 |

    distribution: [

### 5.2 后端：新增 AI 洞察 API

**`POST /api/ai/insight`**

请求体：
```json
{
  "period": "week",
  "insightData": {
    "summary": { "totalDays": 5, "mainEmotion": "焦虑", "avgIntensity": 6.2 },
    "distribution": [...],
    "trend": [...]
  }
}
```

返回：AI 生成的一段文字分析（调用 DeepSeek）。

### 5.3 前端：新增页面

**文件**：`src/views/mood/MoodInsight.vue`

**组件树**：
- `MoodInsight.vue`（主页面）
  - 时间切换栏（日/周/月/年）
  - 概览卡片 x3（记录天数、主要情绪、平均强度）
  - `EmotionPieChart.vue`（情绪分布饼图，ECharts）
  - `IntensityTrendChart.vue`（强度趋势折线图，ECharts）
  - `PolarityBarChart.vue`（正负情绪占比，ECharts）
  - `AiInsightCard.vue`（AI 分析卡片）

### 5.4 路由注册

在 `src/router/index.ts` 的情绪模块下新增：
```typescript
{
  path: '/mood/insight',
  name: '情绪洞察',
  icon: 'fas fa-chart-pie',
  component: () => import('@/views/mood/MoodInsight.vue'),
}
```

## 六、我的额外建议

除了你提的需求，我还建议加这几样小东西，让体验更好：

### 6.1 情绪词云
在 AI 分析卡片上方放一个情绪词云（echarts-wordcloud 已安装），用不同大小和颜色展示用户最近的情绪关键词，一眼就能看到"最近什么情绪最多"。

### 6.2 连续记录天数
在概览卡片区加一个"连续记录 X 天"，给用户正向激励，鼓励坚持记录。

### 6.3 情绪日记联动
点击图表上的某个日期，弹出该日期的情绪记录详情（情绪、事件描述、标签），让图表"可交互"。

### 6.4 导出功能
加一个"导出报告"按钮，把当前视图的图表+AI 分析生成一个 PDF 或图片，用户可以保存或分享给心理咨询师。

## 八、我的想法

你的需求方向完全正确。现在你的产品是"能记录但不能理解"，加上洞察页之后就变成了"记录→理解→改善"的闭环。这个页面的核心价值在于：

1. **图表让数据可视化**——用户不用看数字，看图就知道趋势
2. **AI 分析让数据有意义**——不是冷冰冰的统计，而是有人情味的解读
3. **时间维度灵活**——日/周/月/年，满足不同场景
