### 2.1 新增 Repository 方法

**文件**: `mood_health_server/src/repositories/moodRepository.ts`

```typescript
// 新增方法：getInsightData
const getInsightData = async (
  userId: number,
  startDate: string,
  endDate: string
): Promise<InsightRow[]> => {
  const [rows] = await db.query<InsightSqlRow[]>(`
    SELECT
      DATE_FORMAT(m.recorded_at, '%Y-%m-%d') AS date,
      et.name AS emotion_name,
      et.code AS emotion_code,
      et.category AS emotion_category,
      et.icon AS emotion_icon,
      AVG(me.intensity) AS avg_intensity,
      COUNT(*) AS record_count
    FROM moods m
    JOIN mood_emotions me ON me.mood_id = m.id
    JOIN emotion_types et ON et.id = me.emotion_type_id
    WHERE m.user_id = ? AND DATE(m.recorded_at) >= ? AND DATE(m.recorded_at) <= ?
    GROUP BY DATE_FORMAT(m.recorded_at, '%Y-%m-%d'), et.name, et.code, et.category, et.icon
    ORDER BY date ASC
  `, [userId, startDate, endDate])
  return rows.map(row => ({...}))
}
```

export const generateInsight = async (ctx) => {
  const { period, insightData } = ctx.request.body

## 3. 前端设计

### 3.1 页面组件树

```
MoodInsight.vue
├── 时间切换栏 (button group)
├── 概览卡片 x3 (summary cards)
├── EmotionPieChart.vue (情绪分布)
├── IntensityTrendChart.vue (强度趋势)
├── PolarityBarChart.vue (正负占比)
└── AI 分析卡片 (文字 + 刷新按钮)
```

### 3.2 数据流

```
MoodInsight.vue
  │ onMounted / watch(period)
  ├─ GET /api/moods/insight?period=week
  │    └─ 更新 summary / distribution / trend / polarity / periodComparison
  │
  ├─ POST /api/ai/insight
  │    └─ 更新 aiAnalysis
  │
  └─ 子组件通过 props 接收数据，用 ECharts 渲染
```

### 3.3 ECharts 图表配置

**饼图** (EmotionPieChart.vue):
- 使用 roseType: 'area' 玫瑰图
- 颜色从 distribution[i].color 取
- legend 在底部

**折线图** (IntensityTrendChart.vue):
- smooth: true 平滑曲线
- areaStyle 半透明填充
- yAxis min: 0, max: 10

**柱状图** (PolarityBarChart.vue):
- stack: 'total' 堆叠
- 三色：绿(正面) 蓝(中性) 橙(负面)

## 4. 数据格式

### 4.1 insight API 响应

```typescript
interface InsightResponse {
  summary: {
    totalDays: number
    totalRecords: number
    mainEmotion: string
    mainEmotionCode: string
    avgIntensity: number
  }
  distribution: Array<{
    name: string; code: string; icon: string
    count: number; percent: number; color: string
  }>
  trend: Array<{
    date: string; avgIntensity: number
    dominantEmotion: string; recordCount: number
  }>
  polarity: {
    positive: number; neutral: number; negative: number
  }
  periodComparison: Array<{
    label: string; positive: number; neutral: number; negative: number
  }>
}
```

## 5. 错误处理

- 无数据：返回空数组，前端显示"暂无数据"
- AI 调用失败：前端显示"AI 分析暂时不可用，请稍后重试"
- 网络错误：前端 catch 后显示错误提示
