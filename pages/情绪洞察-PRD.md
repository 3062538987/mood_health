# 情绪洞察 - 产品需求文档 (PRD)

## 1. 产品背景

当前系统支持情绪记录（MoodRecord）和情绪档案（MoodArchive），但用户记录完情绪后无法看到任何数据分析和趋势洞察。用户需要一个页面来"看懂"自己的情绪变化规律。

## 2. 用户故事

- 作为学生用户，我想看到本周我的情绪变化趋势，了解自己什么时候情绪最好/最差
- 作为学生用户，我想看到不同情绪类型的占比，知道哪种情绪出现最多
- 作为学生用户，我想获得 AI 对我的情绪数据的解读和建议
- 作为学生用户，我可以在日/周/月/年四个维度切换查看

## 3. 功能需求

### 3.1 时间维度切换

页面顶部提供四个时间维度切换按钮：日、周、月、年。

| 维度 | 数据范围 | 图表粒度 | 默认值 |
|------|----------|----------|--------|
| 日 | 今天 | 按小时 | - |
| 周 | 最近7天 | 按天 | 是 |
| 月 | 最近30天 | 按天 | - |
| 年 | 最近12个月 | 按月 | - |

### 3.2 概览卡片

三个数字卡片，展示当前时间维度的核心指标：

- **记录天数**：有情绪记录的天数
- **主要情绪**：出现次数最多的情绪名称
- **平均强度**：所有记录的情绪强度平均值（1-10）

### 3.3 情绪分布饼图

展示各情绪类型在所选时间范围内的占比，使用 ECharts 饼图，每种情绪使用对应颜色。

### 3.4 情绪强度趋势图

展示情绪平均强度随时间的变化，使用 ECharts 折线图，X 轴为日期，Y 轴为强度。

### 3.5 正负情绪占比图

展示正面/中性/负面情绪的占比，使用 ECharts 堆叠柱状图，按周/月分组对比。

### 3.6 AI 情绪分析

调用 DeepSeek API，将聚合后的数据发送给 AI，生成一段人性化的文字分析，包含：
- 情绪概况描述
- 规律发现
- 改善建议

## 4. 非功能需求

- 页面首次加载时间 < 2 秒
- 图表渲染流畅，切换时间维度时图表重新加载
- 数据为空时显示引导文案"暂无记录，开始记录情绪吧"
- 移动端适配，图表在小屏幕上可正常显示

## 5. 技术约束

- 复用现有 `moodRepository` 的 `listAnalysisRows` 和 `listTrendRows` 方法
- 复用现有 `callChatCompletion` 调用 DeepSeek API
- 使用已安装的 ECharts 5.x 渲染图表
- 路由放在 `/mood/` 下，作为 MoodLayout 的第三个子路由
- 后端 API 遵循现有成功/失败响应格式（`apiSuccess`/`apiError`）
